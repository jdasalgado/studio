New Features & Attributes Summary

Feature Entity / Table Attributes / Columns Description
Damage / Lost Check-in InventoryBorrowing status, returnCondition, returnNotes Flags items as PENDING when damaged or lost; prevents automatic restoration into available inventory.
Accessories Verification InventoryBorrowing checkoutChecklist, returnChecklist JSON fields storing which accessories (Battery, Lens, SD Card, etc.) were issued vs returned or lost.
Damage Photo Evidence InventoryBorrowing returnPhotos Stores photos captured via mobile camera or uploaded during check-in inspection.
Resolution & Stock Restore InventoryBorrowing, InventoryItem, InventoryLog dueDate, status, quantity Tracks target resolution date; restores item stock and writes audit log once resolved.
Incident Report PDF Client Export Engine generateIncidentReportPDF() Compiles borrowing details, photo evidence, accessories status, and signatures into dark blue PDF.
