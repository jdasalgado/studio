📌 Key Features & Field Breakdown

A. InventoryBorrowing (Check-in, Damage & Loss Tracking)

Field Type Description & Application
status String Supports PENDING for returned damaged/lost items awaiting repair/replacement before restoration to stock.
checkoutChecklist Json Stores array of issued accessories / gear inclusions (e.g. Battery, SD Card, Tripod, Bag).
returnCondition String Records Good Condition, Damaged, Lost, Missing Gear, or Resolved.
returnChecklist Json Stores return checklist results, missing gear list, and target resolution date.
returnPhotos String[] Array of damage evidence images captured at the moment of equipment check-in.
dueDate DateTime Serves as both return deadline and target settlement/resolution deadline when item is damaged/lost.

B. IncidentReportPDF (Auto-Generated File)

Component Functionality
Header & Branding Church title, RPT-XXXX ID, dark navy blue theme (#1c4184), timestamp.
Equipment & Borrower Two-column breakdown of item specs and responsible worker info.
Accessories Status Table Clear audit of each included accessory with ✓ RETURNED or ✗ LOST tag.
Damage Evidence Photo Inline embedded damage photo evidence.
Signatures Section Borrower, Staff, and Authorized Approver sign-off blocks.
